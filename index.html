免费汇率 JSON

每小时尝试更新一次，美元（USD）为基准，覆盖上游提供的全部货币。无需注册或 API Key。

访问最新汇率 latest.json

GET https://haxqer.github.io/FreeExchangeRateStatic/latest.json

rates.CNY 表示 1 美元兑换的人民币数量。任意货币换算：金额 × rates[目标货币] ÷ rates[原货币]。

timestamp 是上游汇率的更新时间（Unix 秒），请在使用时检查数据是否足够新。

数据来自 FreeExchangeRateApi。获取失败时保留上一份有效数据。
